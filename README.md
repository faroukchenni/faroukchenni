### 🔭 What I'm working on

- 🤖 **Production AI assistant for Ozone Voyages** (travel agency, Tunisia) — answers trip, price and booking questions in French, Arabic and English. Hybrid dense + sparse retrieval in Qdrant with cross-encoder reranking, a router that sends structured questions to SQL and open ones to the vector index, and automatic Gemini ↔ Groq fallback. Runs on FastAPI + Qdrant + n8n on a Hetzner VPS behind Caddy, with Messenger, Instagram and WhatsApp integrations.
